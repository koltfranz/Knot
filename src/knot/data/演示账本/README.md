# 演示账本

结绳 Knot 的功能示例：**覆盖全部语法与全部图表**，可以直接拿来试命令，也可以当作自己账本的起点。
数据是虚构的（2025-09 ~ 2026-09，约 380 笔），不含任何真实信息。

复制到任意目录：

```bash
knot 示例                    # 复制到当前目录下的「演示账本/」
knot 示例 我的示例            # 或指定目录名
knot 示例 --打开              # 复制后直接进终端界面（一步到位）
```

仓库里还有一键入口：Windows 双击 `演示.bat`（或 `演示.ps1`），macOS / Linux 执行 `./演示.sh` ——
都是「复制示例（已存在则跳过）+ 直接进终端界面」。

## 文件结构

| 文件 | 内容 |
|---|---|
| `main.knot` | 账本入口：`option` 选项 + `include` 引入 |
| `2025.knot` | 科目开立、期初、定期模板、预算、报价、事件、中英关键字混写、2025 年流水 |
| `2026.knot` | 2026 年流水、结账（`close`）与余额断言（`balance`） |
| `别名.knot` | 别名（`招行 = 资产:银行:招行` 等） |
| `规则/分类规则.knot` | 收款方 → 科目的分类规则 |
| `README.md` | 本文件 |

## 快速开始

```bash
knot open 演示账本                      # 终端界面（鼠标单击选择、Ctrl+单击多选、滚轮滚动）
knot --账本 演示账本/main.knot 检查      # 校验：应为 0 错误
knot --账本 演示账本/main.knot 报 概况   # 概览
```

## 命令示例（都已在本账本上验证）

### 查询与报表

```bash
knot --账本 演示账本/main.knot 查 --月 2026-09            # 当月流水
knot --账本 演示账本/main.knot 查 --标签 旅行              # 按标签
knot --账本 演示账本/main.knot 查 --sql "SELECT 合计(金额) FROM 分录 GROUP BY 科目 ORDER BY 合计(金额) DESC LIMIT 5"
knot --账本 演示账本/main.knot 余 --树 --深度 2            # 科目余额树
knot --账本 演示账本/main.knot 报 收支 --年 2026           # 月度收支
knot --账本 演示账本/main.knot 报 分类 --前 10             # 支出分类
```

### 七种图表（`-o` 写文件，省略则输出 SVG）

```bash
knot --账本 演示账本/main.knot 图 支出 -o 收支.svg                  # 柱：月度收支
knot --账本 演示账本/main.knot 图 净资产 -o 净值.svg                # 线：净资产趋势
knot --账本 演示账本/main.knot 图 分类 -o 分类饼.svg                # 饼：支出分类占比
knot --账本 演示账本/main.knot 图 分类 --类型 树 -o 分类树.svg      # 树：分类面积
knot --账本 演示账本/main.knot 图 日历 -o 日历.svg                  # 热力：消费日历
knot --账本 演示账本/main.knot 图 预算 -o 预算.svg                  # 仪表：预算进度
knot --账本 演示账本/main.knot 图 现金流 -o 瀑布.svg                # 瀑布：现金流
```

### 记账增强

```bash
knot --账本 演示账本/main.knot 预算                       # 预算进度（含超支标记）
knot --账本 演示账本/main.knot 定期                       # 定期模板（房租）
knot --账本 演示账本/main.knot 定期 --月 2026-09           # 该月展开预览
knot --账本 演示账本/main.knot 对账 资产:银行:招行          # 账实比对
knot --账本 演示账本/main.knot 持仓                        # 成本、市值、盈亏（FUND / USD）
knot --账本 演示账本/main.knot 别名 列表
knot --账本 演示账本/main.knot 别名 测试 咖啡
```

### 浏览器界面

```bash
knot --账本 演示账本/main.knot 服务 --打开浏览器
```

## 覆盖的语法与功能

- **标志**：`*` 已确认、`!` 待确认、`?` 待分类（待分类交易可用 `knot 归类` 批量处理）、`P` 已对账
- **分录写法**：单腿 + `@ 对手科目`、多腿自动配平、极简（省略对手科目走默认资产）
- **指令**：`option` / `include` / `open` / `close` / `balance`（余额断言）/ `price`（报价）/
  `commodity` / `recur`（定期模板）/ `budget`（预算）/ `event`（事件）
- **金额与成本**：千分位、多币种（CNY / USD）、成本 `{单价 币种}`、`@ 单价`、`@@ 总价`
- **中文能力**：中文金额（`2万3`）、中文日期（`昨天`）、别名、拼音检索、全角归一化
- **元数据**：分录级 `; 键: 值`（如凭证路径）、标签 `#标签`、链接 `^项目`
- **中英关键字混写**：`2025.knot` 中有一段用英文书写，与中文完全等价
- **三端共用**：同一份账本供 CLI / TUI / 浏览器界面使用，图表结构（ChartSpec）三端一致

## 鼠标操作（TUI）

| 操作 | 效果 |
|---|---|
| 单击流水行 | 选中该笔 |
| Ctrl+单击 / Ctrl+拖动 | 多选（行首出现 ✓，状态栏显示笔数与收支合计） |
| 滚轮 | 在流水 / 科目树中上下滚动 |
| 单击科目树节点 | 选中；再次单击同一节点折叠 / 展开 |
| 单击底部提示条 | 等同于按下对应按键（如 `t` 图表排行） |
| 键盘等价 | `空格` 标记、`b` 批量操作（汇总 / 打标签 / 导出 / 删除）、`Esc` 清空选择 |

> 终端需支持鼠标上报：Windows Terminal / conhost、macOS Terminal、常见 Linux 终端均可；
> 若终端不支持，键盘操作完全等价。

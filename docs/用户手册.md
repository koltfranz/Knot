# 结绳 Knot 用户手册

| 项 | 值 |
|---|---|
| 适用版本 | 0.2.0 |
| 适用平台 | Windows / macOS / Linux |
| 面向读者 | 使用者（非开发者） |

结绳是一个**纯文本复式记账**工具：账本是普通的 `.knot` 文本文件，程序只负责解析、校验与增量写回。

---

## 1 安装与启动

### 1.1 环境要求

- Python ≥ 3.11（推荐 3.13+）
- 无需任何第三方包，安装后不再需要联网

### 1.2 安装

```bash
git clone https://github.com/koltfranz/Knot.git
cd Knot
python -m venv .venv
.venv\Scripts\pip install -e .        # Windows
# source .venv/bin/activate && pip install -e .   # macOS / Linux
```

也可以不安装，直接在仓库目录用 `python -m knot` 代替下文所有 `knot`：

```bash
PYTHONPATH=src python -m knot 记 38 餐饮 -f 现金
```

### 1.3 启动与账本位置

```bash
knot 余                              # 读取当前目录的 main.knot
knot --账本 D:\账本\main.knot 余      # 指定其它位置
```

`--账本`（别名 `--ledger`）是全局参数，写在子命令之前。

### 1.4 Shell 补全（可选）

```bash
knot --补全 bash > ~/.knot-completion.bash   # 再 source 该文件
knot --补全 zsh  > ~/.zfunc/_knot
knot --补全 fish > ~/.config/fish/completions/knot.fish
```

### 1.5 一键运行（推荐给不熟悉命令行的场景）

不想折腾安装时，有四条通道，按场景选：

| 场景 | 方式 |
|---|---|
| Windows 双击就用 | 双击仓库里的 **`knot.bat`**（首次会自动建 `.venv` 并安装，只需联网一次） |
| macOS / Linux | `./knot.sh`（同上，脚本会自动准备环境） |
| 完全离线、随身携带 | 下载 Release 里的 **`knot.pyz`**，用 `python knot.pyz 记 38 餐饮 -f 现金` |
| 已有环境 | `pip install -e .` 后用 `knot` |

不带参数运行时，启动脚本会进入**交互菜单**（记一笔 / 查流水 / 看余额 / 校验 / 规范化 / 初始化新账本 / 退出），也可以直接运行 `knot 菜单`。

### 1.6 生成一个新账本

```bash
knot 初始化 我的账本                # 交互式问答（目录、币种、关键字语言）
knot 初始化 我的账本 --非交互        # 全部取默认值，便于脚本化
knot 初始化 我的账本 --语言 en       # 关键字用英文（option / open / balance）
```

生成内容：

```
我的账本/
├── main.knot          # 选项 + include
├── 2026.knot          # 五大科目 open、期初示例、教学注释
├── 别名.knot          # 招行 / 微信 / 咖啡 等示例别名
├── 规则/分类规则.knot  # 空模板，导入账单时自动套用
└── .gitignore
```

已存在的文件默认跳过（加 `--覆盖` 才重写），生成后会自动跑一次 `检查` 并打印结果。

## 2 账本文件

### 2.1 推荐的目录结构

```
我的账本/
├── main.knot          # 主账本：选项、include、期初
├── 2026.knot          # 年份文件：当年的交易与断言
├── 别名.knot          # 自定义别名（可选）
└── 规则/
    └── 分类规则.knot   # 收款方 → 科目 的自动分类规则（可选）
```

`main.knot` 里用 `include` 组装：

```knot
option "operating_currency" "CNY"
option "default_asset"      "资产:现金"
option "default_income"     "收入:其他"
option "strict"             "warn"

include "别名.knot"
include "规则/分类规则.knot"
include "20*.knot"
```

| 特殊文件 | 作用 |
|---|---|
| `别名.knot` | 用户别名，格式 `别名 = 目标`，每行一条 |
| `规则/分类规则.knot` | 自动分类规则，格式 `收款方 = 科目`，由 `--收款方` 记账时自动追加 |

### 2.2 编码与行尾

- 文件为 UTF-8；读取兼容 BOM，兼容 LF 与 CRLF，写回沿用文件既有风格
- 注释以 `;` 开头，整行或行尾皆可
- 分录相对指令行缩进（推荐 2 空格），程序会沿用你文件里的缩进宽度

### 2.3 最小可运行账本

```knot
option "operating_currency" "CNY"
option "default_asset" "资产:现金"

2026-01-01 open 资产:现金 CNY
2026-01-01 open 权益:期初

2026-01-01 * "期初"
  资产:现金     5,000.00 CNY
  权益:期初
```

### 2.4 与 Git 配合

账本是文本，建议直接纳入 Git：

```bash
git init
git add main.knot 2026.knot
git commit -m "chore: 记录 9 月账目"
```

`记` 只改动受影响的行，因此每次提交的 diff 就是当天记的账，便于回溯。

## 3 记账：`记`

### 3.1 基本用法

```bash
knot 记 38 餐饮 -f 现金 -n 午饭
```

| 参数 | 说明 |
|---|---|
| `金额` | 必填（可用中文数字，见 3.4） |
| `科目` | 必填（可用别名，见 3.6） |
| `-f, --from` | 资金从哪个科目来（支出默认取 `default_asset`） |
| `-t, --to` | 资金去向哪个科目（收入默认取 `default_income`） |
| `-d, --date` | 交易日期，默认今天（见 3.5） |
| `-n, --note` | 摘要 |
| `--收款方` | 收款方名称，同时沉淀分类规则 |
| `--标签` | 标签，可重复：`--标签 工作 --标签 报销` |

### 3.2 收入与支出方向

| 命令 | 含义 | 写入账本 |
|---|---|---|
| `knot 记 38 餐饮 -f 现金` | 花 38 元 | `费用:餐饮 38.00`，`资产:现金 -38.00` |
| `knot 记 5000 工资 -t 招行` | 收入 5000 元 | `收入:工资 -5,000.00`，`资产:银行:招行 5,000.00` |

规则：费用类金额为正，收入类金额为负，对手科目取反——这是复式记账的借贷方向。

### 3.3 转账

```bash
knot 记 500 资产:现金 -f 招行     # 从招行取出 500 变成现金
knot 记 500 资产:现金 -t 招行     # 现金 500 转入招行
```

`-f` 表示本腿为正（钱进来），`-t` 表示本腿为负（钱出去）。资产与负债科目必须给出 `-f` 或 `-t`。

### 3.4 金额写法

| 写法 | 含义 |
|---|---|
| `38` `38.5` `1,234.56` | 普通数字 |
| `¥38` `38元` `38块5` | 货币符号与口语单位 |
| `3千` `1.5万` `3k` | 中文单位 |
| `2万3` | 23000（余数按单位的十分之一计） |
| `3千5` | 3500 |
| `1亿2千万` | 120000000 |
| `-173` | 负数 |

### 3.5 日期写法

| 写法 | 含义 |
|---|---|
| `今天` `今日` `today` | 当天（默认） |
| `昨天` `昨日` `yesterday` `前天` `明天` | 相对日期 |
| `9月20日` `9月20号` | 当年 9 月 20 日 |
| `2026年9月20日` `2026-09-20` `2026/9/20` `9/20` `9-20` | 绝对日期 |
| `上周一` … `上周日` | 上一个自然周的指定日 |

### 3.6 科目与别名

- 科目用冒号分层：`资产:银行:招行`
- 内置别名可直接用：`现金` `招行` `建行` `支付宝` `微信` `信用卡` `花呗` `工资` `奖金` `餐饮` `早餐` `午餐` `外卖` `交通` `打车` `地铁` `房租` `水电` `购物` `医疗` `娱乐` `教育` `人情` `待分类`，以及五大科目根缩写 `A` `L` `E` `I` `X`
- 写入 `别名.knot` 后即可使用自己的简称；同名时用户别名优先于内置
- 匹配到多个候选时会列出编号让你选择；未声明的科目即用即建

### 3.7 收款方、摘要与标签

```bash
knot 记 38 餐饮 -f 现金 --收款方 星巴克 -n 拿铁 --标签 工作
```

写入结果：

```knot
2026-09-25 "星巴克" "拿铁" #工作
  费用:餐饮  38.00 CNY  @ 资产:现金
```

### 3.8 分类规则沉淀

带 `--收款方` 记账后，`收款方 → 科目` 会追加到 `规则/分类规则.knot`（若主账本 include 了该文件），后续导入账单时可直接套用。

### 3.9 交互式记账

不带参数运行 `knot 记`，会依次询问金额与科目（适合不熟悉命令行时使用）。

### 3.10 写入位置与增量写回

- 交易按日期插入到**对应年份文件**（若年份文件已被 `include`）；找不到年份文件时写入主账本
- 只改动受影响的行，未编辑行的字节保持不变
- 写入为原子操作（临时文件 + 替换），中途失败不会破坏原账本
- 块与块之间保持恰一个空行

### 3.11 关键字中英双写

账本里的关键字**中英文等价**：`开立` 与 `open`、`断言` 与 `balance`、`定期` 与 `recur` 效果完全相同，可以混写（例如中文指令配英文周期）：

```knot
选项 "记账币种" "CNY"          ; 等价于 option "operating_currency" "CNY"
2026-01-01 开立 资产:现金 CNY    ; 等价于 2026-01-01 open 资产:现金 CNY
2026-01-01 定期 "monthly" "房租" 起 2026-01-01 止 2026-12-01
```

写回语言规则：**默认按文件跟随**（文件里既有指令是英文就继续写英文，否则写中文），可用 `option "关键字语言" "英文"` 强制。`整理`、`规范` 不会改变你已有的写法。

完整对照表见 [语法大全](./语法大全.md) 与 [语法速查](./语法速查.md)。

### 3.12 账单导入：`导入`

```bash
knot 导入 微信   账单.csv                 # 写入账本
knot 导入 支付宝 账单.csv --试运行         # 只看报告，不写入
knot 导入 银行   流水.csv --账户 资产:银行:招行
knot 导入 微信   账单.csv --json
```

- 支持微信支付、支付宝（GBK 自动探测）、银行流水（单列金额或 收入/支出 两列）三种 CSV
- 自动跳过表头前的说明行，按列名定位（不怕列顺序变化）
- **去重**：按「日期 + 金额 + 收款方」与账本已有条目比对，重复导入不会产生重复交易
- **分类**：先查 `规则/分类规则.knot`；未匹配的支出落入 `费用:待分类` 并标 `?` 标志
- 导入报告：总行数 / 可导入 / 重复 / 待分类 / 解析失败

## 4 查询：`查` 与 `余`

### 4.1 `knot 查`

```bash
knot 查 --月 2026-09
knot 查 咖啡 --科目 费用:餐饮 --从 2026-01-01 --到 2026-09-30
knot 查 --标签 工作 --最少金额 100 --条数 20
```

| 参数 | 说明 |
|---|---|
| `关键词` | 匹配科目、收款方、摘要，可多个 |
| `--月` | 月份：`2026-09`、`2026年9月`、`本月`、`上月` |
| `--年` | 年份：`2026` |
| `--从` `--到` | 起止日期，可与其他条件组合 |
| `--科目` | 科目及其子科目 |
| `--标签` `--收款方` | 精确过滤 |
| `--最少金额` `--币种` | 金额与币种过滤 |
| `--条数` | 只显示最后 N 笔 |
| `--json` | 输出结构化 JSON，便于管道处理 |

输出为一行一条分录：日期、标志、摘要/收款方、科目、金额、币种。

### 4.2 `knot 余`

```bash
knot 余                     # 全部科目余额
knot 余 资产:银行            # 只看某科目及其子科目
knot 余 --树 --深度 2        # 树形，含子科目小计
knot 余 --json              # JSON（按科目、币种）
```

示例（树形）：

```
资产      -5,588.00 CNY
  现金    -5,588.00 CNY
费用      10,588.00 CNY
  居住    10,500.00 CNY
    房租  10,500.00 CNY
```

### 4.3 报表：`knot 报`

```bash
knot 报                       # 概况：交易数、科目余额、收支、净资产
knot 报 收支 --月 2026-09      # 月度收支表（收入 / 支出 / 净额）
knot 报 净资产                 # 每月月末净资产趋势
knot 报 分类 --前 10           # 支出分类排行（可按 --深度 控制聚合层级）
knot 报 科目 --科目 餐饮        # 单个科目的月末余额与每月发生额
knot 报 收支 --json            # 结构化输出，便于脚本处理
```

报表类型也接受英文写法（`summary` / `income` / `networth` / `category` / `account`）。时间范围用 `--月` / `--年` / `--从` / `--到`。

### 4.4 图表：`knot 图`

```bash
knot 图 支出 --按 分类                  # 支出分类占比（饼图），SVG 输出到屏幕
knot 图 净资产 --类型 线 -o 净值.svg      # 净资产趋势折线，写入文件
knot 图 支出 --类型 树 -o 分类.svg        # 分类面积图（treemap）
knot 图 日历 --年 2026 -o 日历.svg        # 消费日历热力图
knot 图 支出 --json                    # 输出 ChartSpec JSON（供 Web / TUI 复用）
```

- 类型：`柱` / `线` / `饼` / `树` / `热力`（英文 `bar` / `line` / `pie` / `treemap` / `heatmap`）
- 输出为自包含 SVG（无外链、无依赖），可直接用浏览器打开或嵌入文档
- 数据点超过 300 个会自动降采样，保证图表可读
- 只在终端看数字时请用 `报`；`图` 面向文件与后续的 Web / TUI

## 5 校验 `检查` 与整理 `整理`

### 5.1 `knot 检查`

```bash
knot 检查            # 输出诊断与统计，正常退出码 0，有问题 1
knot 检查 --静默      # 只在出错时输出，适合脚本
```

诊断分三级，形如：

```
2026.knot:22:1  警告：未声明科目：费用:餐饮:食材
  22 |   费用:餐饮:食材     128.00 CNY
       ^^^^^^^^^^^^^^
  提示：是否意为 "费用:餐饮:早餐"？（相似度 0.75）
```

校验内容：借贷平衡、单腿配平、库存与成本、余额断言、会计恒等式、科目声明（受 `strict` 控制）。

### 5.2 作为 Git pre-commit

```sh
cat > .git/hooks/pre-commit <<'EOF'
#!/bin/sh
knot --账本 main.knot 检查 --静默 || exit 1
EOF
chmod +x .git/hooks/pre-commit
```

### 5.3 `knot 整理`

把分录的科目与金额列对齐，便于阅读与 diff：

```bash
knot 整理           # 就地整理所有已加载的账本文件
knot 整理 --检查     # 只检查是否需要整理，需要则退出码 1
```

整理只调整空白，不改动数值；结果稳定（重复执行不再变化）。

### 5.4 `knot 规范`（全角 / 半角一键规范化）

手写或用别处粘贴的账本常混入全角标点（`：` `，` `“”` `＠` `￥`），解析会报错。`规范` 一键修正：

```bash
knot 规范                          # 全角 → 半角（句法层），就地修正
knot 规范 --试运行                  # 只看报告，不写文件
knot 规范 --检查                    # 需要规范化时退出码 1（可用于提交前检查）
knot 规范 --修复未闭合               # 顺带补全未闭合的引号与花括号
knot 规范 --范围 全部 --方向 半→全    # 把引号内的英文标点转成中文标点
knot 规范 --json                    # 结构化报告（改动明细、问题行号）
```

原则：**句法层一律半角**（解析器要求），引号内的自然语言默认不动，只有 `--范围 全部` 才会改引号里的文本；数字中的小数点与千分位不会被 半→全 误伤。转换幂等，重复执行不再产生变化。

## 6 别名管理：`别名`

```bash
knot 别名 列表
knot 别名 添加 星巴克 费用:餐饮:咖啡
knot 别名 删除 星巴克
```

- 别名写入主账本同目录的 `别名.knot`
- 目标必须是完整科目名（含 `:` 或为五大科目根）或命令关键字（如 `记 = add`）
- 同名时用户别名优先于内置别名

## 7 账本语法（手写参考）

> 完整的中英关键字对照与全部写法见 [语法大全](./语法大全.md)；一页纸速查见 [语法速查](./语法速查.md)。
> 以下为常用写法摘要，关键字可中英混用。

### 7.1 指令全集

| 指令 | 语法 |
|---|---|
| 选项 | `option "键" "值"` |
| 引入 | `include "路径或通配符"` |
| 开立 | `2026-01-01 open 资产:银行:招行 CNY` |
| 关闭 | `2026-12-31 close 权益:期初` |
| 余额断言 | `2026-10-01 balance 资产:银行:招行 14,500.00 CNY` |
| 报价 | `2026-06-01 price FUND 4.1200 CNY` |
| 商品 | `2026-01-01 commodity FUND` |
| 定期交易 | `2026-01-01 recur "monthly" "房租" from 2026-01-01 to 2026-12-01` + 分录 |
| 预算 | `2026-01-01 budget monthly 费用:餐饮 2000.00 CNY` |
| 事件 | `2026-01-01 event "生日" "妈妈"` |
| 交易 | 见 7.2 |

### 7.2 交易与分录

```knot
日期 [标志] ["收款方"] ["摘要"] [#标签…] [^链接…]
  [; 元数据键: 值]
  科目  [金额] [币种] [{成本}|@单价|@@总价] [@对手科目]
```

- 一个字符串时视为摘要，两个字符串时依次为收款方与摘要
- 金额省略币种时取科目默认币种（默认 `operating_currency`）

### 7.3 标志

| 标志 | 含义 |
|---|---|
| `*` | 已确认（默认，可省略） |
| `!` | 待确认 |
| `?` | 待分类 |
| `P` | 已对账 |

### 7.4 自动配平与对手科目

- **单腿简写**：`@ 资产:现金` 指定对手科目，系统自动生成反向分录（不写回文件）
- **自动配平**：一笔交易中恰有一腿金额留空时，由系统补足其相反数

```knot
2026-01-12 * "饭钱"          ; 资产:现金 自动补 -88.00
  费用:餐饮:聚餐   88.00 CNY
  资产:现金
```

### 7.5 成本与多币种

```knot
2026-03-02 * "买入沪深300"
  资产:投资:沪深300     1000 FUND {3.8500 CNY}   ; 成本基础
  资产:银行:招行      -3,850.00 CNY
```

`@ 4.10 CNY`（单价）、`@@ 4100.00 CNY`（总价）为分录内成交信息。

### 7.6 标签、链接、元数据

```knot
2026-01-10 * "团建 AA" #工作聚餐 ^proj-2026Q1
  ; 凭证: ./凭证/2026-01-10-团建.jpg
  费用:餐饮:聚餐      180.00 CNY  @ 资产:现金
```

### 7.7 定期交易

```knot
2026-01-01 recur "每月" "房租" from 2026-01-01 to 2026-12-01
  费用:居住:房租   3,500.00 CNY  @ 资产:银行:招行
```

周期支持 `daily` `weekly` `monthly` `quarterly` `yearly` 及中文 `每天` `每周` `每月` `每季度` `每年`。展开结果仅存在于内存（查询与报表可见），**不会写回文件**。

### 7.8 选项

| 键 | 取值 | 默认 |
|---|---|---|
| `operating_currency` | 币种代码 | `CNY` |
| `strict` | `off` / `warn` / `on` | `warn` |
| `account_language` | `zh` / `en` | `zh` |
| `default_asset` | 科目 | `资产:现金` |
| `default_income` | 科目 | `收入:其他` |
| `write_bom` | `on` / `off` | `off` |
| `sort_accounts` | `unicode` / `pinyin` | `unicode` |
| `pinyin` | `on` / `off` | `off` |

**宽容度**：`off` 科目即用即建、提示级；`warn` 未声明科目给警告（默认）；`on` 科目必须先 `open`，未声明即报错。

## 9 常见问题

**中文显示成乱码？**
程序已在启动时把控制台切到 UTF-8；若仍有问题，确认终端字体与代码页（Windows 可执行 `chcp 65001`）。

**输入全角标点会失败吗？**
不会。`：` `，` `（）` 全角数字、全角空格、`￥` 都会自动归一化为半角。

**提示「科目名非法」？**
科目名只允许中文、字母、数字、下划线与连字符，层级用 `:` 分隔；纯数字会被当作金额，含空格的名称请先用别名指向完整科目。

**提示「借贷不平衡」？**
检查该笔交易各行金额之和是否为 0（多币种需按成本计价平衡），或是否漏写了自动配平腿。

**记不了账，提示「请先修复账本」？**
账本存在错误级问题时，`记`／`查`／`余` 会拒绝执行。先运行 `knot 检查` 按诊断定位修复。

**金额被算错了？**
金额全程使用十进制 `Decimal`，不会出现浮点误差；若与预期不符，用 `knot 查 --json` 核对具体分录。

**如何备份？**
账本本身就是全部数据，复制目录或用 Git 推送即可，不存在隐藏数据库。

**可以在手机或多人协作下用吗？**
当前版本是本地单人工具，不含服务端；多人或多端编辑请依赖 Git 合并。文件锁与冲突检测（开发文档 R4）尚未实现，不建议两端同时写入同一账本。

如果只是想在手机或另一台电脑上看账本，可在本机启动 Web 服务（见第 10 章），用同一局域网访问——注意仅限可信网络。

## 10 浏览器界面（本地服务）

命令行之外，Knot 自带一个**本地**网页界面，零依赖、不联网、不建数据库：后端只读账本产出 JSON，写操作仍走同一套增量写回。

```bash
knot 服务                      # 默认 http://127.0.0.1:5000/
knot 服务 --端口 8080          # 换端口
knot 服务 --静默               # 不打印访问日志
```

页面（左侧导航）：

| 页面 | 能做什么 |
|---|---|
| 仪表盘 | 交易数/科目数/待分类概览、净资产趋势、月度收支、支出分类占比、消费日历、最近流水 |
| 记一笔 | 表单记账（支持别名与中文数字），提交后立即写回账本 |
| 流水 | 按月份/科目/标签/收款方/关键词过滤；**待分类批量归类**（选目标科目一键改账并沉淀规则） |
| 科目 | 科目树（含子科目小计）与每个科目的余额走势迷你图 |
| 报表 | 资产负债表、利润表、现金流量表，以及月度收支/净资产/分类 |
| 导入向导 | 填账单路径 → 预览（可导入/重复/待分类计数与样例）→ 确认写入 |

**实时刷新**：页面通过 SSE（`/api/变更`）监听账本文件变化，命令行里记完账，浏览器会自动刷新。

**安全约束**（务必留意）：

- 默认只监听 `127.0.0.1`，仅本机可访问
- 绑定 `0.0.0.0` 等非本机地址时**必须**设置口令：`knot 服务 --host 0.0.0.0 --口令 s3cret`；口令可通过请求头 `X-Knot-Token` 或 `?口令=` 传入（非 ASCII 口令请用 URL 编码形式）
- **不得把该服务直接暴露到公网**：它没有用户体系，只有可选的单一口令

### 10.1 HTTP 接口（供脚本与第三方界面）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/概览` | 交易数、科目数、待分类、诊断计数 |
| GET | `/api/流水` | 支持 `月/科目/标签/收款方/关键词/条数` |
| GET | `/api/余额` / `/api/科目` | 科目树与余额、科目走势 |
| GET | `/api/待分类` | 待分类聚合（按收款方） |
| GET | `/api/别名` | 用户与内置别名 |
| GET | `/api/报表/资产负债表`（利润表 / 现金流量表 / 收支 / 净资产 / 分类） | 报表数据 |
| GET | `/api/图表/净资产`（收支 / 分类 / 树 / 日历） | ChartSpec JSON（与 CLI、TUI 同一结构） |
| GET | `/api/变更` | SSE 变更推送 |
| POST | `/api/记一笔` | 记账（体：金额/科目/来自/去向/日期/摘要/收款方/标签） |
| POST | `/api/归类` | 待分类批量归类（体：收款方/科目） |
| POST | `/api/导入预览` / `/api/导入` | 账单预览与写入（体：来源/文件/账户） |

中文路径在 HTTP 层需按 URL 规则转义（浏览器与 `curl --data-urlencode` 会自动处理）。

## 12 记账增强：预算 · 对账 · 定期 · 拼音

### 12.1 预算与进度

预算写在账本里，与交易同源：

```knot
2026-01-01 budget monthly 费用:餐饮 2,000.00 CNY
```

用命令查看进度：

```bash
knot 预算                 # 最近有交易的月份
knot 预算 --月 2026-09     # 指定月份
knot 预算 --json
knot 图 预算 --月 2026-09 -o 预算.svg    # 进度条形图（ChartSpec，三端一致）
```

输出会给出每个预算科目的预算 / 实际 / 剩余 / 进度百分比，超支的科目单独标红。预算进度也可以直接在 Web 界面「报表 → 预算进度」查看。

### 12.2 对账

```bash
knot 对账 招行                          # 只看账实情况与待对账清单
knot 对账 招行 --余额 17,280.00           # 与账单余额比对，差额不为 0 时退出码 1
knot 对账 招行 --余额 17,280.00 --标记     # 把待对账交易标为 P（已对账）
knot 对账 招行 --余额 17,280.00 --断言     # 同时写入 balance 断言，之后 `检查` 会复验
knot 对账 招行 --json
```

- 「待对账」= 该科目下未标 `P` 的交易（按日期倒序）
- 提示信息会判断「差额是否正好等于待对账合计」，帮助你区分漏记与未达账项
- `--断言` 写入的断言遵循文件既有的关键字语言（中文账本写 `断言`，英文账本写 `balance`）

### 12.3 定期交易

```bash
knot 定期                    # 列出模板：周期、说明、起止、下次发生、分录数
knot 定期 --月 2026-09        # 该月由模板展开出的交易
knot 定期 --json
```

模板语法：

```knot
2026-01-01 recur "monthly" "房租" from 2026-01-01 to 2026-12-01
  费用:居住:房租   3,500.00 CNY  @ 资产:银行:招行
```

展开只发生在内存（查询、报表、预算都能看到），**不会写回文件**。

### 12.4 拼音检索

任何要求科目名的地方都支持拼音：

```bash
knot 记 38 xianjin -f zhaohang      # 现金 / 招行
knot 余 zhaohang
knot 查 --科目 fycywm
knot 别名 测试 fycy                 # 看看会解析成什么
```

规则：输入为纯 ASCII 字母时，按**全拼**（`xianjin`）或**首字母**（`xj`）匹配科目名；前缀命中优先，命中多个会列出候选让你写全。

knot 别名 添加 咖啡 费用:餐饮:咖啡
knot 别名 测试 咖啡
knot 别名 删除 咖啡

# 结绳 Knot v0.8.2 发布说明

发布日期：2026-09-29　上一版本：v0.8.1

补丁版：**只修缺陷，不新增功能**。本版修的是"发布流水线"这条链路——它此前一直没把产物交到用户手里。

## 修复内容

### 1. 发布页长期没有任何附件

Release 工作流只把 `knot.pyz` 与三平台可执行程序上传成 **CI 工作流制品**（`actions/upload-artifact`），
从来 `gh release upload` 到 GitHub Release，因此发布页是空的，而文档里写的是「Release 附件里的 `knot.pyz`」。

现在：`zipapp` 与三平台 `nuitka` 作业在构建完成后都会把产物挂到对应 Release；
若 Release 尚不存在，会按 `docs/发布说明/<tag>.md`（有则用、无则自动生成）创建；
工作流声明了 `permissions: contents: write`，并支持 `workflow_dispatch` 手动重跑。

同时已为既有的 **v0.8.0** 与 **v0.8.1** 补挂 `knot.pyz`（各自由对应 tag 构建，`--version` 分别显示 0.8.0 / 0.8.1）。

### 2. Windows 可执行程序从未产出

Windows 的 Nuitka 作业会**挂死 6 小时后被取消**：Nuitka 为探测 DLL 依赖会运行
`depends.exe`（Dependency Walker），而它在 GitHub 的 Windows 运行器上不退出。
日志显示 12:23 启动 `depends.exe`，直到 18:21 被取消，期间没有任何输出。

现在 Windows 改用 `--windows-dependency-tool=pefile` 解析依赖（Nuitka 自带该工具），
不再调用 `depends.exe`。

## 兼容性

- 账本文件、命令、配置均无变化；v0.8.1 可直接升级
- 本版**不含** main 上尚未发布的一键体验示例账本（`演示.bat` / `示例 --打开`），
  该功能随下一个功能版本发布
- 本版从 v0.8.1 拉出维护分支 `release/v0.8.2` 发布，main 保持前进

```bash

knot --version               # 应显示 0.8.2
```

# 结绳 Knot v0.9.0 发布说明

发布日期：2026-09-29　上一版本：v0.8.2

本版把「怎么打开」这件事收敛成**一个入口**：装完就有一个「结绳 Knot」图标，双击弹选择窗口，
浏览器界面 / 终端界面 / 示例账本三选一。仓库里此前那一堆启动脚本（`knot.bat`、`界面.*`、`网页.*`、`演示.*`）
**全部删除**。账本语法保持冻结，本版**没有**破坏既有 `.knot` 文件的变更。

## 亮点

### 1. 一个入口，三种打开方式

安装后（`安装.ps1` / `安装.sh`）会自动创建入口：

| 平台 | 入口位置 |
|---|---|
| Windows | 桌面 + 开始菜单「结绳 Knot」快捷方式（`pythonw.exe -m knot 入口`，无黑窗） |
| macOS | `~/Applications/结绳 Knot.app`（启动台 / 应用程序可见） |
| Linux | `~/.local/share/applications/knot.desktop`（应用菜单可见） |

双击后弹出**选择窗口**（只用系统自带工具实现，零第三方依赖）：

| 选项 | 行为 |
|---|---|
| **浏览器界面**（默认，10 秒后自动进入） | 启动本地服务并打开浏览器：仪表盘、流水、科目、报表、7 种图表、导入向导 |
| **终端界面** | 在新窗口打开三栏界面，鼠标可用：单击选择、`Ctrl`+单击多选、滚轮滚动、`b` 批量菜单 |
| **示例账本** | 复制内置示例账本（约 380 笔、覆盖全部语法与 7 种图表）并打开浏览器界面 |

### 2. 账本主页 `~/结绳账本`

入口总要有个默认账本：首次运行会在 `~/结绳账本` 自动生成账本骨架（含可直接修改的默认内容与注释示例），
随即就能记账。想换位置：`KNOT_HOME` 环境变量或 `knot 入口 --账本目录 路径`。

### 3. 启动脚本全部下线（破坏性变更）

删除的脚本（13 个）：`knot.bat`、`knot.sh`、`knot.ps1`、`界面.bat/.sh/.ps1`、`网页.bat/.sh/.ps1`、
`演示.bat/.sh/.ps1`。仓库根目录只保留 `安装.ps1`、`卸载.ps1`、`安装.sh`、`卸载.sh`。

替代方式（按场景）：

| 场景 | 方式 |
|---|---|
| 已安装 | 双击入口，或命令行 `knot 入口` |
| 未安装、想零配置试一下 | Release 附件：`python knot.pyz 入口` |
| 仓库内开发 | `PYTHONPATH=src python -m knot 入口` 或 `pip install -e .` 后用 `knot 入口` |

命令行等价（跳过选择窗口）：

```bash
knot 入口 --界面 浏览器     # 打开账本主页的浏览器界面
knot 入口 --界面 终端       # 打开账本主页的终端界面
knot 入口 --界面 示例       # 复制示例账本并打开浏览器界面
```

### 4. 终端界面提示常驻

状态栏常驻一行操作提示：`单击选择 / Ctrl+单击多选 / 滚轮滚动 / 空格标记 / b 批量菜单 / ? 帮助 / q 退出`。

## 修复内容

- Release 上传附件时把 Nuitka 的 `*.dist` 中间目录也交给 `gh release upload` 导致步骤报错，
  现在只上传可执行文件本身

## 兼容性

- **账本文件无需改动**：语法仍为 v0.7.0 冻结状态
- **仓库启动脚本已删除**（见上）：如果此前依赖 `界面.bat` / `网页.bat` / `演示.bat`，请改用入口或 `knot 入口`
- 命令行与账本目录结构不变；`knot 示例`、`knot 打开`、`knot 服务`、`knot 界面` 等命令照旧可用

## 已知边界

- **Windows 不再产出 Nuitka 可执行程序**（Linux / macOS 照旧）：Nuitka 在 Windows 上会调用
  `depends.exe` 探测 DLL 依赖，在无交互运行器上会挂死（曾两次各跑满 6 小时被取消）；
  Nuitka 4.x 已移除 `--windows-dependency-tool` 选项。Windows 用户请用免安装的 `knot.pyz`
  （只需 Python ≥3.11）或 `安装.ps1`（推荐）
- 选择窗口依赖系统工具：Windows PowerShell、macOS osascript、Linux zenity/kdialog；
  缺失时退回终端菜单，非交互环境直接走默认项（浏览器界面）
- 无终端环境（桌面双击）下，终端界面在新窗口里跑；若系统没有可用终端模拟器会给出命令行提示
- 其余同 v0.8.x：无文件锁与多端冲突检测；PyPI 未发布；Docker 镜像未在本机验证

## 升级方式

```bash
git pull                     # 或下载 Release 附件
sh ./安装.sh                 # 升级安装（Windows：.\安装.ps1）
knot --version               # 应显示 0.9.0
knot 入口                     # 试试新入口（也会用上桌面/应用菜单里的图标）
```

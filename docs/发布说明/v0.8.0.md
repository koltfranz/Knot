# 结绳 Knot v0.8.0 发布说明

发布日期：2026-09-27　上一版本：v0.7.0（语法冻结）

本版主题是**交互与分发**：账本可以「命名」了，终端界面能用鼠标（含多选与批量操作），
并提供 Windows / macOS / Linux 的**一键安装与一键卸载**，外加一本开箱即用的示例账本。
账本语法保持冻结，本版**没有**破坏既有 `.knot` 文件的变更。

## 亮点

### 1. 命名账本：`新建` / `打开`

```bash
knot 新建 我的账本        # 生成账本目录（含可直接修改的默认内容）
knot 打开 我的账本        # 直接进入终端界面（--网页 走浏览器界面）
```

- 默认内容自带「去掉行首 `;` 即可用」的示例段：单腿 / 多腿、标签与元数据、待分类、定期、预算、
  报价与成本、余额断言、结账、事件——测试保证这一段解注释后**校验零错误**
- `打开` 会先校验账本；不是交互式终端时退回输出概况，方便脚本与 CI

### 2. 终端界面支持鼠标与批量操作

| 操作 | 效果 |
|---|---|
| 单击 | 选中流水 / 科目树节点 |
| `Ctrl`+单击、`Ctrl`+拖动 | 多选（行首 `✓`，状态栏显示笔数与收支合计） |
| 滚轮 | 流水 / 科目树滚动 |
| 点击底部提示条 | 等同于按下对应按键 |
| `空格` / `b` / `Esc` | 键盘等价：标记 / 批量菜单 / 清空选择 |

批量菜单提供：**汇总**（笔数与收支合计，转账不虚增）、**打标签**、**导出**（CSV / JSON）、
**删除**（写回前生成时间戳 `.bak` 备份 + 二次确认）。由 `定期` 模板展开的交易以 `⟳` 标注，
不参与编辑与批量写回。Windows 走控制台输入事件（自动关闭快速编辑），POSIX 走 SGR 鼠标上报；
终端不支持鼠标时键盘操作完全等价。

### 3. 一键安装与一键卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\安装.ps1     # Windows
```
```bash
sh ./安装.sh                                           # macOS / Linux
```

- 独立虚拟环境（Windows：`%LOCALAPPDATA%\Programs\Knot`；macOS / Linux：`~/.local/share/knot`）
- 全局 `knot` 命令（Windows 用户 PATH + `knot.cmd` / `knot.ps1` 垫片；POSIX `~/.local/bin` 软链）
- 安装即验证：自动运行 `knot 自检`；`install.json` 记录版本、来源与安装时间
- 卸载**不依赖 Python**、**不删除账本**；若安装目录内有 `.knot` 文件会明确提示
- 两端都支持 `-DryRun` / `--dry-run` 与 `-NoPath` / `--no-path`；重复执行安装即升级

### 4. PowerShell 支持

- `knot.ps1` / `界面.ps1` / `网页.ps1` 一键启动器（UTF-8 BOM + CRLF，中文提示不乱码）
- `knot --补全 powershell`（别名 `pwsh`）生成 `Register-ArgumentCompleter` 补全脚本

### 5. `自检`（doctor）与示例账本

```bash
knot 自检        # Python 版本 / 控制台编码 / ANSI-VT / 交互终端 / 账本 / 目录可写 / 别名与规则文件
knot 示例        # 复制内置示例账本：13 个月、约 380 笔、0 错误 0 警告，覆盖全部语法与 7 种图表
```

## 缺陷修复

- **P0**：终端界面里按 `e` 编辑摘要，若选中的是 `定期` 模板展开出的交易，会按模板行区间写回，
  **把模板替换成一笔普通交易**（账本损坏）。现在这类交易禁止直接编辑，列表以 `⟳` 标注并提示改模板
- **P1**：`定期` 命令永远显示「账本里还没有定期交易模板」——模板展开后 `Recur` 对象被丢弃，
  命令拿不到模板（模板现保留在 `book.recur_templates`）
- **P1**：`定期` 命令列出模板时崩溃（`分录` 计数是整数，表格按显示宽度渲染时报 `TypeError`）
- **P1**：`ORDER BY 合计(金额) DESC` 报「无法解析 ORDER BY」——手册里的聚合排序示例一直不可用
- Windows `卸载.ps1` 误报「已从用户 PATH 移除」（未包含该条目时不再改动 PATH）
- 删除交易块后残留空行：现在一并清理块后的空行

## 兼容性与升级说明

- **账本文件无需改动**：语法仍为 v0.7.0 冻结状态，既有的 `.knot` 文件可直接使用
- `新建` 别名由 `初始化`（`init`）移交给 `新建`（`create`）；`初始化` 行为不变
- 终端界面代码量预算由 800 行上调至 1500 行（新增鼠标、Windows 控制台事件层与批量操作）
- `.ps1` 统一为 UTF-8 BOM + CRLF；`.gitattributes` 已声明 `*.ps1 text eol=crlf`
- 批量删除的备份 `*.bak` 已加入 `.gitignore` 与骨架模板

## 已知边界

- 文件锁与多端冲突检测（风险 R4）仍未实现：多端编辑请依赖 Git 合并
- PyPI 尚未发布（`安装.ps1 -From knot-ledger` 已为此预留）；Docker 镜像仍未在本机验证
- 终端鼠标依赖终端上报支持：Windows Terminal / conhost、macOS Terminal 与常见 Linux 终端可用；
  不支持时自动降级为键盘操作
- 批量删除只提供账本文件级备份（`.bak`），不提供撤销栈

## 升级方式

```bash
git pull                     # 或下载 Release 附件
sh ./安装.sh                 # 重复执行安装脚本即升级
knot --version               # 应显示 0.8.0
```

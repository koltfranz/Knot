## 1 目标与范围

一句话目标：**让账本从「能用」变成「好上手、能中英双写、能读报表、能导入账单」**。

四条主线：

| 组 | 主题 | 内容 |
|---|---|---|
| A | 语言完备 | 关键字中英双写（指令、选项、周期），语法大全文档由代码生成 |
| B | 数据清理 | 全角 / 半角一键规范化，含未闭合引号与不配对括号的检测与修复 |
| C | 上手体验 | 一键运行 CLI（启动脚本 + zipapp），`初始化` 命令生成账本骨架 |
| D | 报表与图表 | `报` / `图` 命令，ChartSpec 与 SVG 输出（原 M1） |
| E | 账单导入 | 微信 / 支付宝 / 银行 CSV 导入、去重、分类（原 M1） |
| F | 文档与发布 | 语法大全定稿、手册增补、发布 v0.2.0 |

版本编排结论：三项新增**并入 v0.2.0**，版本总数与 `v0.7.0` 稳定化不变。

## 2 任务分解

复杂度：小 ≈ 单模块；中 ≈ 模块 + 命令 + 测试；大 ≈ 跨模块 + 多种输入形态。

### A 语言完备：关键字中英双写

| 编号 | 任务 | 产出 | 复杂度 |

| A2 | 解析接入双语 | `lexer.py` / `parser.py` 接受中英两种写法；记录每个文件的关键字语言 | 中 |

| A4 | 诊断词表双语 | 诊断与提示文案按当前文件语言选择词表（`i18n.py` 扩展） | 小 |

| 编号 | 任务 | 产出 | 复杂度 |
|---|---|---|---|
| B1 | 全 → 半（句法安全集） | `core/convert.py`：`：，（）？！；％／－＿　￥０-９Ａ-Ｚａ-ｚ＠＃＾｛｝“”` → 半角 | 中 |
| B2 | 半 → 全（中文标点集） | 同上模块：`, . ! ? ( ) [ ] { } " '` → `，。！？（）【】｛｝“”`，仅对引号内文本生效 | 中 |

### C 上手体验：一键运行与账本生成

| 编号 | 任务 | 产出 | 复杂度 |
|---|---|---|---|
| C1 | 账本骨架生成器 | `core/scaffold.py`：模板与幂等/覆盖策略（已存在文件默认跳过） | 小 |
| C2 | `初始化` 命令 | `cli/commands/init.py`：向导（问目录、币种、默认科目）与 `--非交互`；生成后自动跑一次 `检查` | 中 |

**一键运行的三条通道**（按场景选择）：

| 场景 | 方式 | 前提 |
|---|---|---|
| 已装 Python，想双击就用 | 双击 `knot.bat` / `./knot.sh` | 首次需联网安装依赖（仅一次） |
| 完全离线、随身携带 | 下载 Release 的 `knot.pyz`，`python knot.pyz 记 …` | 只需 Python ≥3.11 |
| 开发者 | `pip install -e .` 后用 `knot` | 需 venv |

`初始化` 生成的骨架：

```
我的账本/
├── main.knot          # 选项 + include
├── 2026.knot          # 五大科目 open、期初示例、教学注释
├── 别名.knot          # 招行 / 微信 / 支付宝 / 工资 / 餐饮 等示例
├── 规则/分类规则.knot  # 空模板
└── .gitignore         # .venv、*.pyz、*.tmp
```

### 3.4 标志（符号固定，中文仅用于展示）

| 符号 | 中文名 | 说明 |
|---|---|---|
| `*` | 已确认 | 默认，可省略 |
| `!` | 待确认 | 需复核 |

### 3.6 标点：半角（英文）与全角（中文）

| 用途 | 半角 | 全角 | 规范化默认 |
|---|---|---|---|
| 科目层级 | `:` | `：` | 半角 |
| 千分位 | `,` | `，` | 半角 |
| 字符串引号 | `"` | `“ ”` | 半角 |
| 注释 | `;` | `；` | 半角 |
| 标签 / 链接 | `#` `^` | `＃` `＾` | 半角 |
| 对手科目 / 成本 | `@` `@@` | `＠` | 半角 |
| 成本括号 | `{ }` | `｛ ｝` | 半角 |
| 货币符号 | `¥` | `￥` | 半角 |
| 数字与字母 | `0-9 A-Z a-z` | 全角形式 | 半角 |
| 全角空格 | 空格 | `　` | 半角 |
| 中文句子内部标点 | `, . ! ? ( )` | `，。！？（）` | 全角（仅 `--范围 全部`） |

**原则**：句法层一律半角（解析器要求）；自然语言文本默认不动，只有在 `--范围 全部` 时才按方向转换。

## 6 实施顺序与依赖

```
A 语言完备 ──┬─→ B 规范化（复用值表与映射）
             ├─→ C 上手体验（写回语言策略先定）
             ├─→ D 报表图表
             └─→ E 账单导入 ──→ F 文档与发布
```

A 先行，避免 D / E 完成后因语言策略变更而返工；B 与 C 可与 D / E 并行推进。

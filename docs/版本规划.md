# 版本规划

本文档定义结绳 Knot 的版本号编排、各版本交付范围与发布门槛。

对应关系：开发文档第 16 章的里程碑（M0–M4）映射为 v0.1.0 – v0.6.0，其后为 v0.7.0 稳定化发布。

## 版本总览

| 版本 | 对应里程碑 | 主题 | 发布门槛 |
|---|---|---|---|
| v0.1.0 | M0 | 内核与 CLI 记账 | 中文一句话记账可用；黄金测试通过；`检查` 可作 Git pre-commit；zipapp 可运行 |
| v0.2.0 | M1 | 报表与账单导入 | 微信 / 支付宝 / 银行三源导入并去重；GBK 编码探测正确；净资产趋势与分类占比图表数据可输出 |
| v0.3.0 | M2 | Web 界面 | 浏览器中完成记账全流程；SSE 增量刷新；默认仅监听 `127.0.0.1` |
| v0.4.0 | M3 | TUI 界面 | 三栏布局键盘流可用；cooked 模式中文输入正常；模块代码量 ≤ 800 行 |
| v0.5.0 | M4 前半 | 记账增强 | 定期交易、预算、对账、拼音检索、别名管理可用且测试覆盖 |
| v0.6.0 | M4 后半 | 投资与多币种 | 成本基础与库存正确；多币种净值折算正确；ChartSpec 三端一致 |
| v0.7.0 | 稳定化 | 格式冻结与分发 | `.knot` 语法冻结；Nuitka 三平台可执行；用户手册与语法速查齐备；数万条交易规模达标；无 P0 / P1 缺陷 |

## 各版本交付范围

### v0.1.0 —— 内核与 CLI 记账（M0）

- `schema/GRAMMAR.md` 定稿
- 中文基础模块：`console.py`、`width.py`、`normalize.py`、`number_cn.py`、`date_cn.py`、`aliases.py`、`i18n.py`
- 数据与解析：`model.py`、`amount.py`、`lexer.py`、`parser.py`、`diagnostic.py`、`loader.py`、`book.py`、`writer.py`
- CLI：`记 / 查 / 余 / 检查 / 整理` 五个子命令
- 测试套件：词法、解析、校验、归一化、中文数字、中文日期、宽度、别名、编码、写回

### v0.2.0 —— 报表与账单导入（M1）

- `report.py` 报表聚合与 `ChartSpec` 中间结构
- 账单导入：`importer/wechat.py`、`alipay.py`、`bank.py`，含编码探测、跳行、表头校验、指纹去重
- 学习式分类规则沉淀至 `规则/分类规则.knot`
- 图表数据：净资产趋势、月度收支对比、支出分类占比、分类趋势、科目余额随时间

### v0.3.0 —— Web 界面（M2）

- `http.server.ThreadingHTTPServer` + 中文路由 `/api/流水` 等
- SSE 变更推送（`os.stat().st_mtime` 轮询，500 ms）
- 页面：仪表盘、记一笔、流水、科目、报表、导入向导
- 前端为随包分发的静态资源，不依赖 CDN

### v0.4.0 —— TUI 界面（M3）

- 自研 ANSI 绘制层：`term.py`、`screen.py`、`theme.py`、`input.py`
- 控件：流水列表、科目树、记账表单、盲文迷你图
- 固定三栏布局与键位，文本字段切换 cooked 模式以支持中文输入

### v0.5.0 —— 记账增强（M4 前半）

- 定期交易模板展开（仅内存实例化，不写回）
- 预算与预算进度
- 对账向导
- 拼音检索（内嵌常用汉字拼音表）
- 别名管理命令完善

### v0.6.0 —— 投资与多币种（M4 后半）

- 成本基础与库存核算
- 多币种账户与 `price` 报价、汇率折算
- 现金流瀑布图、预算仪表盘、消费日历热力图
- SQL 子集查询（`SELECT` / `WHERE` / `GROUP BY` / `ORDER BY`）

### v0.7.0 —— 稳定化发布

- `.knot` 语法冻结，写入手册与速查
- Nuitka 三平台可执行程序，CI 矩阵构建
- `docs/用户手册.md`、`docs/语法速查.md` 定稿
- 性能验收：数万条交易规模
- 缺陷清理：无 P0 / P1

## 版本号策略

- 版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)
- `0.x` 阶段为开发期，**不承诺向后兼容**；破坏性变更允许出现在次版本（如 `0.3.0` → `0.4.0`）
- 补丁版 `0.x.y` 仅修复缺陷，不新增功能
- **`1.0.0` 及以上的版本号 MUST 经项目所有者明确许可后方可规划**，在此之前最高规划至 `v0.7.0`
- 版本号在 `pyproject.toml` 单点维护，起始值 `0.1.0`；后续由 `src/knot/version.py` 读取

## 发布流程

```
1. 开发分支合入 main
2. 更新 CHANGELOG：Unreleased → [版本号] - 日期
3. 升级 pyproject.toml 中的 version
4. 打 tag：git tag v0.x.0
5. 推送 tag 并创建 GitHub Release
6. 发布 PyPI（首次发布前完成 15.5 部署前检查）
```

# 结绳 Knot 语法大全

| 项 | 值 |
|---|---|
| 适用版本 | 0.2.0 |
| 状态 | 定稿 |
| 对照表来源 | `src/knot/core/keywords.py`（单一事实源，由脚本生成） |

本页是**命令行与账本语法的完整参考**。账本中的关键字**中英文等价**：写 `open` 与写 `开立` 效果完全相同。

> 对照表由 `python scripts/生成语法大全.py` 生成，`tests/test_keywords.py` 断言文档与代码一致；
> 校验命令：`python scripts/生成语法大全.py --检查`。

---

## 1 写回语言规则

| 情形 | 写回用的关键字语言 |
|---|---|
| `option "keyword_language" "中文"` | 一律中文 |
| `option "keyword_language" "英文"` | 一律英文 |
| 未设置（默认 `跟随`） | **按文件跟随**：文件里既有指令是英文就写英文，否则中文 |

`整理`、`规范` 等命令不会改变文件中既有的关键字语言；解析时两种写法可混用（例如中文指令 + 英文周期）。

## 4 账本行结构

```knot
; 顶层指令从第 1 列开始
2026-01-01 开立 资产:现金 CNY

日期 [标志] ["收款方"] ["摘要"] [#标签…] [^链接…]
  [; 元数据键: 值]
  科目  [金额] [币种] [{成本} | @单价 | @@总价] [@对手科目]
  科目  [金额] [币种] …
```

| 元素 | 写法 | 说明 |
|---|---|---|
| 日期 | `2026-01-01` | 文件内 MUST 为 ISO 格式 |
| 标志 | `*` `!` `?` `P` | 见对照表；不可中文书写 |
| 字符串 | `"收款方"` `"摘要"` | 一个字符串时视为摘要，两个时依次为收款方与摘要 |
| 金额 | `38` `38.00` `-1,234.56` | 文件内为普通数字；中文数字仅用于命令行输入 |
| 币种 | `CNY` `USD` `FUND` | 省略时取科目默认币种 |
| 成本 | `{3.8500 CNY}` `@ 4.10 CNY` `@@ 4100.00 CNY` | 成本 / 单价 / 总价 |
| 对手科目 | `@ 资产:现金` | 单腿交易自动生成反向分录 |
| 标签 / 链接 | `#工作` `^proj-1` | 名称内不含空白 |
| 元数据 | `; 凭证: ./x.jpg` | 归属最近的主体（交易头部或分录） |
| 注释 | `; 说明文字` | 不匹配元数据形式时仅作注释 |

## 6 标点与全角规则

| 用途 | 半角（句法） | 全角（等价输入） | 规范化默认 |
|---|---|---|---|
| 科目层级 | `:` | `：` | 半角 |
| 千分位 | `,` | `，` | 半角 |
| 引号 | `"` | `“ ”` | 半角 |
| 注释 | `;` | `；` | 半角 |
| 标签 / 链接 | `#` `^` | `＃` `＾` | 半角 |
| 对手科目 / 成本 | `@` `@@` | `＠` | 半角 |
| 成本括号 | `{ }` | `｛ ｝` | 半角 |
| 货币符号 | `¥` | `￥` | 半角 |
| 数字与字母 | `0-9 A-Z a-z` | 全角形式 | 半角 |
| 全角空格 | 空格 | `　` | 半角 |
| 中文句子标点 | `, . ! ? ( )` | `，。！？（）` | 全角（仅 `--范围 全部`） |

**原则**：句法层一律半角；引号内的自然语言文本默认不动，只有 `--范围 全部` 才按方向转换。

```bash
knot 规范                          # 全角→半角（句法层），就地修正
knot 规范 --试运行                  # 只看报告
knot 规范 --范围 全部 --方向 半→全    # 引号内文本转为中文标点
knot 规范 --修复未闭合               # 补全未闭合引号与花括号
knot 规范 --检查                    # 退出码 1 表示需要规范化
```

## 7 命令行输入：中文数字与中文日期

| 类别 | 可用写法 |
|---|---|
| 金额 | `38` `38.5` `1,234.56` `¥38` `38元` `38块5` `3千` `1.5万` `2万3` `3千5` `1亿2千万` |
| 日期 | `今天` `昨天` `前天` `明天` `9月20日` `2026年9月20日` `9-20` `2026-09-20` `上周一` |
| 月份 | `本月` `上月` `今年` `2026-09` `2026年9月` |
| 科目 | 别名（`招行` `微信` `餐饮` `房租`…）、五大科目根缩写（`A` `L` `E` `I` `X`）、完整科目名 |
| 拼音 | 纯字母时按拼音匹配：`xianjin`、`zhaohang`（全拼）或 `xj`、`fycywm`（首字母），多命中列出候选 |

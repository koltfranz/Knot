# 结绳 Knot 语法速查（一页纸）

| 适用版本 | 0.7.0（**语法冻结**：既有写法不再变更，只新增可选写法） |
|---|---|

> 完整参考见 [语法大全](./语法大全.md)；使用教程见 [用户手册](./用户手册.md)。

## 启动

```bash
knot 初始化 我的账本            # 生成账本骨架（main.knot + 年份文件 + 别名 + 规则）
knot --账本 我的账本/main.knot 记 38 餐饮 -f 现金 -n 午饭
knot 菜单                      # 交互菜单（或双击 knot.bat / ./knot.sh）
```

## 命令

| 命令 | 别名 | 例子 |
|---|---|---|
| `add` | `记` | `记 38 餐饮 -f 现金 -n 午饭` ／ `记 5000 工资 -t 招行` |
| `show` | `查` | `查 --月 2026-09` ／ `查 咖啡 --科目 费用:餐饮 --json` |
| `bal` | `余` | `余` ／ `余 --树 --深度 2` |
| `report` | `报` | `报 收支 --月 2026-09` ／ `报 分类` ／ `报 科目 --科目 餐饮` |
| `chart` | `图` | `图 支出 --按 分类` ／ `图 净资产 -o 净值.svg` |
| `check` | `检查` | `检查`（退出码 0/1，可作 pre-commit） |
| `fmt` | `整理` | `整理` ／ `整理 --检查` |
| `import` | `导入` | `导入 微信 账单.csv` ／ `导入 支付宝 账单.csv --试运行` |
| `normalize` | `规范` | `规范` ／ `规范 --试运行` ／ `规范 --修复未闭合` |
| `init` | `初始化` | `初始化 我的账本 --非交互` |
| `alias` | `别名` | `别名 添加 星巴克 费用:餐饮:咖啡` |

全局：`--账本 路径`、`--补全 bash|zsh|fish`、`--version`；退出码 `0` 正常 / `1` 校验失败 / `2` 用法错误 / `130` 中断。

## 关键字（中英等价）

| 英文 | 中文 | 英文 | 中文 |
|---|---|---|---|
| `option` | `选项` | `recur` | `定期` |
| `include` | `引入` | `budget` | `预算` |
| `open` | `开立` | `event` | `事件` |
| `close` | `关闭` | `from` / `to` | `起` / `止` |
| `balance` | `断言` | `price` | `报价` |
| `commodity` | `商品` | `daily` / `monthly` / `yearly` | `每天` / `每月` / `每年` |

选项键：`operating_currency`/`记账币种`、`strict`/`严格度`、`default_asset`/`默认资产`、`default_income`/`默认收入`、`keyword_language`/`关键字语言`、`account_language`/`科目语言`。
写回语言默认**按文件跟随**，可用 `option "keyword_language" "en"` 强制英文。

## 账本写法

```knot
; 交易：单腿 + 对手科目（反向分录自动生成）
2026-09-25 "午饭"  费用:餐饮  38.00 CNY  @ 资产:现金

; 多腿：留空的一腿自动配平
2026-09-26 * "超市"
  费用:餐饮:食材 128.00 CNY
  资产:现金

; 成本与多币种
2026-09-27 * "买入"
  资产:投资:沪深300  1000 FUND {3.8500 CNY}
  资产:银行:招行   -3,850.00 CNY

; 断言 / 定期 / 预算 / 事件
2026-10-01 balance 资产:银行:招行 14,500.00 CNY
2026-01-01 recur "monthly" "房租" from 2026-01-01 to 2026-12-01
  费用:居住:房租 3,500.00 CNY @ 资产:银行:招行
2026-01-01 budget monthly 费用:餐饮 2000.00 CNY
2026-01-01 event "生日" "妈妈"

; 标签 / 链接 / 元数据
2026-10-02 * "团建" #工作 ^proj-1
  ; 凭证: ./凭证/团建.jpg
  费用:娱乐  120.00 CNY  @ 资产:现金
```

标志：`*` 已确认（可省略）、`!` 待确认、`?` 待分类、`P` 已对账。

## 命令行输入

| 类别 | 写法 |
|---|---|
| 金额 | `38` `1,234.56` `¥38` `38块5` `3千` `2万3` `1亿2千万` |
| 日期 | `今天` `昨天` `9月20日` `2026-09-20` `上周一` |
| 月份 | `本月` `上月` `今年` `2026-09` |
| 科目 | 别名（`招行`/`微信`/`餐饮`）、科目根缩写（`A` `L` `E` `I` `X`）、完整名 |

## 标点与规范化

句法层一律半角：`:` `,` `"` `;` `#` `^` `@` `{` `}` `¥`。

```bash
knot 规范                      # 全角 → 半角（句法层）
knot 规范 --范围 全部 --方向 半→全   # 引号内文本转中文标点
knot 规范 --修复未闭合           # 补全未闭合引号与花括号
```

## 账本目录

```
我的账本/
├── main.knot          # 选项 + include
├── 2026.knot          # 年份文件（`记` 按日期插入）
├── 别名.knot          # 别名 = 目标
└── 规则/分类规则.knot   # 收款方 = 科目（导入时自动套用）
```

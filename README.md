# 结绳 Knot

> 以纯文本文件为唯一数据存储的个人复式记账系统，提供 CLI / TUI / Web 三种操作界面。

**结绳记事**是人类最早的记账形式。项目取"绳结"之意——每一笔交易是一个结，整本账是串起来的绳。与纯文本账本"用最朴素符号记录金钱"的设计哲学一致。

| 项 | 值 |
|---|---|
| 包名 / 命令名 | `knot` |
| 语言 | Python ≥ 3.11（推荐 3.13+） |
| 运行时依赖 | **无**（仅 Python 标准库） |
| 目标平台 | Windows / macOS / Linux |
| 适用地区 | 中国大陆（人民币本位、中文输入、中文会计科目） |
| 许可证 | GPL-3.0 |

## 特性

- **文本唯一真相**：账本是人可直接阅读、可用任意文本编辑器修改、可纳入 Git 版本管理的 `.knot` 文本文件，不引入数据库
- **零依赖内核**：Core 模块不依赖任何第三方包与 UI 框架
- **增量写回**：写操作仅修改受影响的行区间，`git diff` 只显示真实变更
- **定点金额**：全程 `decimal.Decimal`，杜绝浮点误差
- **中文友好**：全角归一化、中文数字（`2万3`、`38块5`）、中文日期（`昨天`、`9月20日`）、中文会计科目与别名系统
- **三端一致**：CLI / TUI / Web 消费同一内核与同一图表中间结构（ChartSpec）

## 快速示例

不想安装时，双击仓库根目录的 `knot.bat`（Windows）或运行 `./knot.sh`（macOS/Linux）：首次会自动准备环境，之后进入交互菜单。

```bash
knot 初始化 我的账本              # 生成账本骨架（加 --非交互 可一键生成）
knot 记 38 餐饮 -f 招行 -n 午饭
knot 记 2万3 房租 -f 招行 --date 昨天
knot 查 --月 2026-09
knot 余 --树 --深度 2
knot 报 收支 --月 2026-09
knot 图 支出 --按 分类 -o 分类.svg
knot 检查
knot 预算                        # 预算进度（超支标红）
knot 对账 招行 --余额 17,280.00    # 对账：差额、待对账清单、--标记/--断言
knot 定期 --月 2026-09            # 定期交易模板与展开预览
knot 记 38 xianjin -f zhaohang   # 拼音也能写科目
knot 持仓                        # 投资持仓、成本基础（FIFO/平均）与盈亏
knot 查 --sql "SELECT 合计(金额) FROM 分录 GROUP BY 科目"   # SQL 子集
knot 图 现金流 -o 瀑布.svg         # 现金流瀑布（期初→经营→投资→筹资→期末）
knot 导入 微信 账单.csv
knot 规范                        # 全角标点一键转半角
knot 服务                        # 浏览器界面（本地 http://127.0.0.1:5000/）
knot 界面                        # 终端三栏界面（TUI）
```

单文件运行（下载 Release 的 `knot.pyz`，只需 Python ≥3.11）：

```bash
python knot.pyz 记 38 餐饮 -f 现金
python knot.pyz 报 净资产
```

账本长这样：

```knot
option "operating_currency" "CNY"

2026-01-01 open 资产:现金     CNY
2026-01-01 open 权益:期初

2026-01-01 * "期初"
  资产:现金     1,000.00 CNY
  权益:期初

2026-09-25 "午饭"    费用:餐饮    38.00 CNY  @ 资产:现金
2026-09-25 "地铁"    费用:交通     6.00 CNY  @ 资产:现金
```

## 安装

开发中，尚未发布至 PyPI。发布后：

```bash
pip install knot
```

本地开发：

```bash
git clone https://github.com/koltfranz/Knot.git
cd Knot
python -m venv .venv
pip install -e .
```
